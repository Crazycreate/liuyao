> 状态:**方案/规划阶段,尚未动工**。目标:把大六壬接进现有 liuyao,与六爻在「同一起卦时刻」上互证。

## 0. 一句话结论

六壬起课**完全由占时决定**,而六爻引擎**已经算了占时干支**——所以「同一心念时刻同时驱动两盘」(方案 A)在现有架构里几乎免费。难点不在接线,而在 **① 六壬起课算法本身是这四套里最易算错的**,和 **② 互证要诚实(两盘共享日辰月将,并非完全独立)**。

- 把 liuyao 从「六爻」扩成「**即时占卜 · 六爻 + 大六壬 互证**」。两者同属「起一卦/课,测一具体事」范式,天然同源。
- **首期**:六壬起课确定性引擎(天地盘/四课/三传/十二天将)+ 六爻已有盘 → AI 分维度互证 → Web 双盘 + 一致度呈现。

## 2. 方案 A:同一心念时刻驱动双系统(架构)

```
用户摇钱币的那一刻  =  心念注入点  =  占时戳记
        │
        ├──→ 六爻:用「摇出的六爻」起卦,占时作月建/日辰背景(已实现)
        └──→ 六壬:用「这一刻的日干支 + 占时支 + 月将」起课(全确定性)
```

**关键复用**:六爻引擎的 `DivineDate` 已含 `年/月/日/时干支`、`月支(月建)`、`日支(日辰)`。六壬起课要的就是 `日干支 + 占时支 + 月将`——只需给 `date.ts` 再补一个 **月将(由中气定太阳过宫)**,六壬即可起课。**两盘共用同一个 `castMoment`,这是「互证成立」的技术前提。**

**一个比「都算一遍」更准的框架**(写进产品文案):
- **六壬 = 当下客观天时盘**:同一分钟,谁起都是同一课。
- **六爻 = 你的心念抽样**:同一分钟,摇出的卦人人不同。
- **互证 = 客观场 ∩ 个人投射**:六壬给「这件事此刻的事态」,六爻给「你与这件事的关系」。两者重合处才高可信。

## 3. 六壬起课确定性引擎(算法分解)

> 全部为精确算法,**绝不让 LLM 生成盘面**。下列每一步都可由 `lunar-javascript`(干支、节气/中气)+ 自写课式表实现。

**步骤链**:月将 → 月将加时(天地盘)→ 四课 → 三传(发用)→ 十二天将 →(年命)。

1. **取月将**(太阳过宫,随中气换):雨水→亥(登明)、春分→戌(河魁)、谷雨→酉(从魁)、小满→申(传送)、夏至→未(小吉)、大暑→午(胜光)、处暑→巳(太乙)、秋分→辰(天罡)、霜降→卯(太冲)、小雪→寅(功曹)、冬至→丑(大吉)、大寒→子(神后)。由 lunar 的中气推。
2. **月将加时 → 天地盘**:地盘十二支固定;天盘 = 把「月将」加在「占时支」之上,余支顺布。实现:`offset = 月将index − 占时index`,`天盘[地盘i] = 支[(i+offset)%12]`。
3. **四课**(日干寄宫:甲寅·乙辰·丙戊巳·丁己未·庚申·辛戌·壬亥·癸丑):
   - 一课:下=日干寄宫支,上=其天盘上神
   - 二课:下=一课上神,上=其天盘上神
   - 三课:下=日支,上=其天盘上神
   - 四课:下=三课上神,上=其天盘上神
4. **三传(发用)· 九宗门**(按序判定取初传,中传=初传之天盘上神,末传=中传之天盘上神):
   - 贼克(下贼上/上克下)→ 比用(取与日干同阴阳者)→ **涉害**(俱比/俱不比时取涉害深者)→ 遥克(蒿矢/弹射)→ 昴星(阳日地盘酉上、阴日天盘酉下)→ 别责(三课不全)→ 八专(干支同位日)→ 伏吟(天地盘同)→ 反吟(天地盘冲)。
5. **十二天将**:贵人歌(甲戊庚丑未、乙己子申、丙丁亥酉、壬癸巳卯、六辛寅午)定贵人,分昼贵/夜贵(昼=卯—申,夜=酉—寅);贵人落地盘 亥—辰顺布、巳—戌逆布;序为 贵·蛇·雀·合·勾·龙·空·虎·常·武·阴·后,贴于天盘。
6. **(进阶)年命**:求测者本命/行年上神作辅。首期可缓。

### ⚠️ 三个最易翻车、必须先写测试的点
- **涉害取用**(三传里最难):逐支回归地盘本家、数所克/受克深浅,流派细节多。
- **贵人顺逆 + 昼夜**:错一处,十二天将整盘错位。
- **伏吟/反吟/八专的特殊三传**:不能套通用「上神链」。

## 4. 课例测试(金标准 + 不变量)

正如「排错一步,满盘皆错」——六壬尤甚。测试分两层:

**A. 精确课例比对(金标准)**:对《大六壬指南》《六壬大全》《大六壬寻源》中的标准课例逐一比对——**九宗门每种至少一例**(重审、元首、比用、涉害、遥克、昴星、别责、八专、伏吟、反吟),核对天地盘、四课、三传、十二天将逐项一致。这是过关的硬指标。

**B. 结构不变量(全覆盖随机校验)**:
- 天地盘旋转一致:`天盘[占时支] == 月将`,十二支不重不漏。
- 四课构造:下神/上神链条正确(2课下=1课上,4课下=3课上)。
- 三传链:非伏吟/反吟/八专时,中传=天盘[初传]、末传=天盘[中传]。
- 十二天将:十二将不重不漏,顺/逆方向与贵人落宫一致。
- 任意时刻起课不抛错(遍历全年×十二时辰抽样)。

## 5. 互证层设计(诚实是卖点)

### 5.1 不给单一百分比 —— 这条关乎诚信
六壬与六爻**共享同一日辰、月建**,不是两个独立信源,而是同一时空的两种投影。**所以「两系统一致」的证据力比直觉弱**,把它包装成「可信度 87%」是不诚实的伪精确。正确做法:**分维度报一致/分歧**,并标注独立性局限。

### 5.2 固定四维度互证(各自取用、再比结论,不做术语硬翻译)
| 维度 | 六爻看 | 六壬看 | 谁更权威 |
|------|--------|--------|---------|
| 成败倾向 | 用神旺衰、动变生克、世应 | 课体吉凶、三传生克日干 | 六爻强(成败力度/动变) |
| 应期 | 动爻值/冲/出空填实 | 三传发用、值神 | 互证(两边都给则可信↑) |
| 人物/方位 | 弱 | 十二天将、类神、方位(强) | **六壬补六爻盲区** |
| 风险/性质 | 凶神(白虎勾陈等无)、忌神动 | 螣蛇惊忧、白虎病丧、玄武盗等天将 | 六壬强(天将刻画) |

> 让 AI 知道「谁在哪一维更可信」,而不是把世爻硬等于日干。用神↔类神**各按各自规矩取**,只比最终结论。

### 5.3 冲突如实呈现
```
本次测算
  成败:两系统一致(偏不成)✓ 高可信
  应期:六爻指申酉月、六壬发用在申 → 一致 ✓
  方位人物:仅六壬给出(求测事在西方,涉一属金之男)
  风险:六壬白虎临用现「阻力/病讯」,六爻无明显凶象 → 分歧,需谨慎
  ——一致处可信,分歧处存疑;且两盘同时同地,非完全独立,仅供参考。
```

### 5.4 解读落到「行动」,防算命焦虑
结论不停在吉凶,落到**「所以你该做什么」**(趋避方向、时机、需留意的人/方位)。

## 6. 铁律:排盘必须确定性,绝不让 LLM 排盘

LLM 会算错日柱、装错卦、起错课;排盘一错,后面解读再好也白搭。**算法排盘(精确)→ LLM 只解读已排好的盘**。六壬尤其要先过课例测试再接 AI。

## 9. 分期里程碑 + 复杂度

| 里程碑 | 范围 | 复杂度 | 依赖 |
|--------|------|--------|------|
| **L0 月将 + 天地盘** | 中气定月将、月将加时 | 中 | lunar 节气 |
| **L1 四课 + 三传** | 寄宫四课、九宗门(含涉害) | **高** | L0;课例测试 |

| **L3 castMoment 双盘同源** | 同一时刻起六爻+六壬 | 低 | 六爻已有 |

建议顺序:L0 → L1(配课例测试,最硬)→ L2 → L3 → L4 → L5。**L1 不过课例测试,后面不开工。**
